# 版本: v2.11

更新时间: 2026-03-27 10:40:00

- 修复 CDN 加速核心链路：开启 `cdn_enabled` 后，主站 ` /cdn_assets/* ` 现改为返回 `302` 到配置的 `cdn_domain`，客户端直接从 CDN 域名拉取图片/视频，显著降低主站带宽占用。
- 新增主站素材路由逻辑：后端增加 `GET /cdn_assets/<path>` 统一入口，开启加速时重定向到 CDN，关闭加速时回落主站本地素材，保持路径兼容。
- 修复 CDN 开关切换缓存干扰：重定向响应增加 `no-store/no-cache` 头，避免宿主机反代缓存与浏览器缓存造成“开关已开但仍走旧链路”的假象。
- 修复旧网关分流策略缺陷：移除 `auth_request_set + if` 造成的分流失效路径，网关改为将主站 ` /cdn_assets ` 请求交由后端动态决策。
- 加固反向代理同源校验：`server.py` 与 `app/routes/admin.py` 同步修复 `X-Forwarded-Host/Proto` 场景下的同源判断，兼容 `http/https` 混合代理与双域名入口，降低误报 403 风险。
- 运维适配增强：补充“宝塔 Nginx 双域名反代（2026/2027）”部署说明，并明确建议关闭反代缓存（或至少对 ` /cdn_assets ` 关闭），防止历史 `404/302` 污染。
- 后台文案与运维说明更新：`站点设置 -> CDN 加速设置` 的操作指南与后端逻辑介绍已更新为 `302 直连 CDN` 模式，减少维护歧义。
