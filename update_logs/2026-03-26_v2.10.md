# 版本: v2.10

更新时间: 2026-03-26 16:35:00

- 新增后台登录人机验证（Cloudflare Turnstile）完整能力：支持在 Admin「站点设置」中在线开启/关闭、配置 Site Key/Secret Key，并在登录页接入验证流程。
- 登录页交互升级：Turnstile 验证组件改为居中显示；未通过验证前登录按钮置灰禁用，通过后自动恢复可点击状态。
- 后台登录态安全策略增强：管理员会话默认 8 小时有效期，到期自动失效并要求重新登录。
- 完成管理员认证体系加固：管理员密码从明文配置迁移为安全哈希存储，并兼容历史数据平滑升级。
- 新增子账号管理能力：支持创建、编辑、启用/禁用、删除子账号，并在账号设置中展示子账号列表。
- 新增细粒度 RBAC 权限控制：侧边栏全部功能项可按子账号逐项授权，后端按接口路径做权限校验。
- 审计能力增强：新增「历史登录日志」分页与只读展示，并修复子账号查看登录日志的权限可见性问题。
- 管理后台体验优化：所有关键操作确认弹窗统一改为屏幕中央模态框，提升可见性与防误操作能力。
- 管理后台信息架构调整：侧栏「留言管理」更名为「仪表盘」，「AI 客服设置」更名为「智能客服」，并将「CDN 加速设置 + 登录机器人验证」独立归档到「站点设置」。
- 新增双入口网关方案：同容器架构下支持主站与 CDN 入口分流（`/cdn_assets` 专用链路），保持页面资源路径不变并支持故障回源兜底。
- 运维部署简化：`docker run` 不再要求传入 `MAIN_DOMAIN/CDN_DOMAIN`；网关默认按端口分流，域名绑定交由 DNS/反向代理层处理。
- CI/CD 发布流程升级：GitHub Release 触发时自动构建并推送两个镜像（website + gateway），便于双容器生产部署。
