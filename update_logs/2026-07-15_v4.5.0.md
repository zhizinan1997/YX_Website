## 【新增：Passkey 无密码登录】

- 新增后台 Passkey 登录入口。浏览器和设备支持 WebAuthn 时，管理员可通过指纹、面容、设备 PIN、安全密钥或密码管理器凭据完成登录。
- 新增 `app/passkeys.py`，使用 SQLite 持久化用户句柄、凭据公钥、签名计数器、设备名称、传输方式、备份状态、最近使用时间与 IP、挑战记录及频率限制。
- Passkey 数据库默认保存为 `data/admin_passkeys.sqlite3`，初始化后尝试设置为仅当前用户可读写，并启用 WAL、外键和忙等待配置。
- 新增后台 Passkey 开关和每账号最大凭据数量配置；超级管理员可在「站点设置 → Passkey 快速登录」中直接启用，无需必须提供环境变量。
- 新增 `PASSKEY_ENABLED`、`PASSKEY_ORIGIN`、`PASSKEY_RP_ID`、`PASSKEY_RP_NAME`、`PASSKEY_DB_PATH`、`PASSKEY_CHALLENGE_TTL_SECONDS` 和 `PASSKEY_MAX_CREDENTIALS_PER_USER` 运维覆盖项。
- 新增 Origin、RP ID 和 HTTPS 安全校验：生产环境要求 HTTPS，RP ID 必须是当前主机或其父域，仅 localhost 允许 HTTP。
- 新增挑战会话绑定、过期控制、单次使用限制和最多三次失败保护，防止挑战重放、跨浏览器复用或暴力尝试。
- 新增每 IP 每分钟频率限制，并校验 WebAuthn 用户验证结果、凭据所属账号和签名计数器，发现计数器回退时拒绝登录。
- 新增 Passkey 添加、列表、重命名和移除功能；添加第一枚 Passkey 前使用安全邮箱验证码二次确认，已有 Passkey 后优先使用现有凭据进行二次验证。
- 高风险操作的二次验证有效期为 10 分钟；移除本人凭据、超级管理员强制吊销子账号凭据等操作均要求重新验证。
- 超级管理员的子账号列表新增 Passkey 数量，并可查看、单独吊销或批量吊销子账号凭据；停用或删除子账号时同步吊销其全部 Passkey。
- 管理员修改用户名时同步迁移 Passkey 归属，避免改名后设备凭据失联。
- 新增安全引导横幅：当管理员尚未验证安全邮箱或尚未绑定 Passkey 时，在后台提示完成账号加固。
- 新增 `admin/js/passkeys.js`，所有 WebAuthn 弹窗仅在用户明确点击登录、添加或验证按钮后触发，避免页面加载时意外唤起系统验证界面。

## 【新增：图片 SEO 资产中心】

- 后台「内容运营」分组新增「图片 SEO」入口，提供图片扫描、状态总览、筛选、分页、批量处理、字段编辑和大图预览。
- 新增全站图片扫描器，覆盖首页、`pages/`、`assets/` 与 `cdn_assets/` 中的图片引用和孤立图片文件。
- 扫描结果会记录图片地址、归属页面、页面类型、角色、Alt、标题、说明、尺寸、MIME、文件大小、内容哈希、引用页面和索引状态。
- 自动识别缺失 Alt、通用 Alt、重复 Alt、关键词堆砌、缺少归属页、文件缺失、大文件、缺少尺寸、重复内容和未被页面引用等问题。
- 图片角色支持主图、详情图、应用场景图、原理示意图、新闻图片、装饰图、Logo、二维码等语义分类；装饰图、Logo 和二维码默认不进入图片索引。
- 支持按关键词、角色、问题类型、页面类型、索引状态和有效/已忽略状态筛选图片。
- 支持逐张编辑归属页、角色、索引状态、Alt、图片标题和图片说明，并支持批量修改选中资产。
- 支持忽略无须处理的图片和恢复已忽略图片；看板汇总会在元数据修改后即时刷新，无需强制重新扫描。
- 新增 Alt 草稿生成，用页面和文件名生成待审核建议，但不会自动持久化或覆盖已有文案。
- 新增中文 CSV 导出，以及带图片缩略图、冻结表头、筛选器、字段说明和下拉校验的 Excel 导出。
- 支持通过 Excel/CSV 回传已编辑元数据；仅覆盖能够按资产编号或图片地址匹配的现有记录，不上传、不替换、不删除图片文件。
- 图片 SEO 写操作统一执行同源校验，并记录扫描、修改、批量处理、忽略、恢复和导入等审计事件。
- 新上传的 CDN 图片和产品卡片图会自动注册到图片 SEO 数据库，减少上传后遗漏归属和审核的概率。
- 新增 `data/image_seo_assets.json`、`data/image_seo_scan_report.json` 和 `data/image_seo_audit.json`，分别保存资产元数据、扫描报告和审计记录。

## 【安全与媒体交付优化】

- 调整反爬虫策略：公开页面、CSS、JavaScript、图片和媒体资源不再仅因 User-Agent 被识别为爬虫而拒绝访问，确保搜索引擎能够完整抓取可公开内容。
- `/admin`、`/api/admin`、`/data/` 和 `/update_logs/` 等私有路径继续对爬虫执行阻断，并保留严格的 `X-Robots-Tag` 防索引响应头。

- CDN 素材继续使用长期不可变缓存和跨域读取策略，图片 SEO 和公开页面可稳定获取正确媒体类型。

- 部署后清理或刷新 ESA/CDN 中的 HTML、`robots.txt` 和 `sitemap*.xml` 缓存，并验证裸域名、`www` 主域名及四类分站点地图。
- 在真实 HTTPS 主域名下启用 Passkey 后，至少完成一次“添加凭据 → 退出 → Passkey 登录 → 重命名 → 二次验证”的完整验收。
- 图片 SEO 首次上线后先执行全站扫描，再由内容负责人审核主图、新闻图和产品图的归属页、角色、Alt、标题与说明，避免未经审核的自动草稿直接用于搜索展示。
- 上线后至少持续 7 天监控 404、301 命中、HTML 缓存、搜索引擎抓取、图片索引、IndexNow/百度推送状态和附件访问情况。
- 清理报告中标记的“全球首款”“国内首创”“国际领先”、技术指标、认证、招标数据和政策引用仍需技术、市场或法务依据原始材料人工复核。
