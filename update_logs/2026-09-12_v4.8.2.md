# 代码变更统计

- **本版本修改代码：约 1,200 行**，涉及 **46 个文件**（含删除监测站全部代码 15 个文件、新增回归测试与更新日志）。
- 统计基线为 v4.8.2 相对于 v4.8.1 的差异。本版本源于一次全量只读安全审查，修复其中可在代码侧闭环的全部 P1/P2 问题与可安全落地的 P3 问题，并按运营决策移除独立监测站。

# 版本: v4.8.2

更新时间: 2026-09-12

## 【版本概览】

- 本版本为**安全加固版本**：修复多 worker 配置保存竞争、SSRF DNS rebinding 窗口、公开埋点写放大（DoS 放大器）、备份权限缺口、两处存储型 XSS、监测服务鉴权边界，以及若干并发与依赖问题。
- 不改变任何前端页面结构与业务 API 行为；部署脚本无需变更（`dockerrun_upgrade.sh` 已显式管理受影响的环境变量）。

## 【P1：埋点日志写放大修复】

- **裁剪逻辑失效导致的全局写放大**：埋点 JSONL 超过 32MB 后，原"按行数保留 200000 行"的裁剪在典型记录体积下永远裁不动，导致之后**每一次公开埋点请求都整读+整写 32MB 文件**并占用全局跨进程文件锁。现改为按字节预算（约体量一半）从尾部回收，并增加"无行可丢则跳过整写"保护（`app/routes/site_analytics.py`）。
- 管理端报表日期区间桶数加硬上限（400 桶），极端区间（如 0001-9999）不再逐日构造百万级字典拖垮 worker。

## 【P2：多 worker 数据一致性】

- **站点配置保存竞争**：`config.json` 的读改写原先进程内线程锁 + 固定名 `.tmp` 临时文件，gunicorn 双 worker 并发保存会互相丢更新、甚至把半截临时内容提交为正式配置。现统一走新增的 `cross_process_file_lock`（线程锁 + flock 可重入组合锁）与唯一临时名原子写（`app/app_config.py`、`app/atomic_io.py`）。
- 留言删除计数、留言已读标记、AI 报表索引等共享 JSON 的读改写补齐同一跨进程锁（`contact_messages.py`、`site_analytics.py`）。
- CDN 素材重命名的"检查存在→改名"窗口加目录级锁，消除并发改名覆盖已有素材的竞态（`cdn_assets.py`）。

## 【P2：SSRF DNS rebinding 闭合】

- 新增 DNS 固定机制：远程抓取校验函数（`validate_safe_remote_fetch_url_detail`）在校验时解析 DNS 并返回已验证 IP，实际请求在**线程级 pin 栈**内把域名解析固定为该 IP——建连、SNI、证书、Cookie 行为不变，"首次解析公网通过校验、二次解析内网完成 SSRF"的窗口不再存在（`app/request_security.py`）。
- 已接入三处远程抓取点：新闻正文/图片导入（requests 与 httpx 双路径、逐跳重定向）、`/api/news/image/import`、`/api/video-proxy` 媒体代理。

## 【P2：后台人机验证与备份】

- **ESA 验证码退化绕过**：provider 为 aliyun_esa 时，原逻辑任意非空 `captchaVerifyParam` 即放行（验签完全依赖边缘规则）。现增加形态门槛（长度 ≥32 且无空白/控制字符），边缘规则缺失时无法再用垃圾字符串绕过；真实 SDK 令牌不受影响（`app/routes/admin.py`）。
- **备份下载收紧为仅超级管理员**：整站备份含全部源码与部署文件，原允许持 backup 权限的子管理员下载，现与恢复操作同级（`app/routes/backup.py`）。
- **恢复屏蔽名单补齐 Web 可执行内容**：`.html/.htm/.xhtml/.svg/.js/.mjs` 不允许经恢复包写入站点目录，堵死"会话被劫持后借恢复植入持久 XSS"的通道；恢复只负责 `data/` 下可变内容，页面与静态资源仍以镜像为准（`app/app_config.py`）。

## 【P2：监测服务（check_app）加固】

- **会话不回查账号状态**：`_login_required` 现在每次请求回查主站 `admin_users.json`，管理员被停用、删除或邮箱解绑后旧会话立即失效，不再残留至自然过期（`check_app/app.py`）。
- **信任代理头默认关闭**：`CHECK_TRUST_PROXY_HEADERS` 默认从 true 改为 false，默认部署下伪造 `X-Forwarded-For: 127.0.0.1` 不再能把请求伪装成 loopback（配合 dev-login 存在条件性提权）；`dockerrun_upgrade.sh` 部署显式传 true，生产行为不变。代理头参与 IP 判定同样受该开关门控。
- **会话密钥持久化**：未显式设置 `CHECK_SECRET_KEY` 时密钥落盘 `check_data/.flask_secret_key`，重启/多 worker 不再全体掉线（`check_app/config.py`）。
- **公开状态页脱敏**：`/api/public/status` 不再返回监测目标错误详情与事件 `last_error`（可能含内网主机名），详情仅保留在管理端接口；验证码发送失败不再把 SMTP 异常原文回显给未认证调用方（`check_app/storage.py`、`check_app/app.py`）。

## 【P2：存储型 XSS】

- 招聘信息标题/部门/地点等纯文本字段在 `clean_job_text` 中先还原实体再剥离内联标签，堵住借 `&lt;img onerror=...&gt;` 实体回流旧版招聘页的存储型 XSS（`app/routes/jobs_content.py`）。
- Mega Menu 推荐位名称保存时剥离内联标签，产品页模板直插 `innerHTML` 的注入面关闭（`app/routes/navigation_content.py`）。

## 【P2：客户端真实 IP 判定适配阿里云 ESA 链路】

- 部署链路为「客户端 → 阿里云 ESA → 宝塔 nginx 反代 → 容器」。原取 IP 逻辑默认优先信任 `CF-Connecting-IP`——这是 Cloudflare 专有头，在阿里云链路中只能来自客户端伪造，等于公开埋点限流键与后台登录地理围栏都可被伪造头绕过（指定一个中国大陆 IP 即可绕过默认"仅放行中国大陆/亚洲"的登录地域策略）。
- 新增环境变量 `REAL_CLIENT_IP_HEADERS`（逗号分隔、按优先级）：配置后进入**严格模式**，只信任 CDN 边缘覆写注入的专用头（ESA「托管转换」注入 `Ali-Real-Client-IP`，CDN/DCDN 默认透传 `Ali-CDN-Real-IP`）；该头缺失（流量绕过 CDN 直连源站）时不回退任何可伪造头，按 XFF 最右公网 → 直连地址收敛。未配置时保持旧行为，向后兼容（`app/request_security.py`、`app/routes/admin.py`、`check_app/app.py`）。
- 部署模板 `.env.example` 已给出推荐值 `Ali-Real-Client-IP,Ali-CDN-Real-IP`；该变量未被升级脚本托管，旧容器上设置后会自动继承到新容器。

## 【P3：其他加固】

- CDN 素材上传改流式限量读取，128MB 上限 × 多线程不再造成整文件读入内存的峰值（`cdn_assets.py`）。
- 移除"主模块是 server.py 即视为开发模式"的兜底启发式：开发模式只认 `APP_ENV`/`FLASK_ENV`，生产误用 `python server.py` 启动不再静默落入弱口令配置（`app/app_config.py`；`server.py` 直跑时本就自带 `APP_ENV=development`，本地开发行为不变）。
- PDF 解析依赖由停维护的 PyPDF2 迁移到其官方延续版 pypdf（API 兼容，保留旧库回落）。

## 【修复：升级脚本交互输入容错】

- **问题**：升级时选择"重置界面（保留用户数据）"等高风险选项后，脚本要求输入确认词（`YES`/`RESET`）；宝塔等 web 终端偶发吞按键/回车变成空行，或用户误把数字再输一遍时，旧逻辑**一次性失败即终止**并提示"未输入确认词"，且确认词区分大小写、无法重试，观感就是"输入了却说没输入"。
- **修复**（`tools/dockerrun_upgrade.sh`）：
  - 确认环节改为容错重问（最多 3 次）：空输入明确提示"终端可能吞掉了按键"并重问；确认词忽略大小写；输错时回显实际收到的内容；输入 `n`/`no`/`取消` 等显式取消词才终止。
  - 更新模式选择后**大声回显实际注册的选择**（如"已选择：3) 重置界面…"），终端丢按键导致空输入回落默认"智能合并"时用户能立刻发现并 Ctrl+C。
  - 无效的 `PUBLIC_BASE_URL` 不再作为默认值回显，避免"按回车永远提交同一个非法值"的死循环。
- 新增 10 个函数级回归用例（确认词大小写/空输入重试/误输重试/取消词/三次失败终止/策略菜单解析），bash 测试 **62 项全过**。

- **后台入口同步移除**：`/admin` 右上角的「网络监测」跳转按钮已删除。
- 服务器侧清理（一次性手工操作，脚本不做）：`docker rm -f yx-check-site`、`docker rmi ghcr.io/zhizinan1997/yx_website-check:latest`、删除宿主机 `/root/yxwebsite/check_data/`，并在 ESA/宝塔里下线 `check.hnmetachip.cn` 的解析与反代。
