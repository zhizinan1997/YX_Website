# 版本: v3.3.1

更新时间: 2026-04-11 22:40:00

## 【新增】
- 后台登录流程升级为“两阶段验证”：账号密码与 Cloudflare Turnstile 校验通过后，可发送邮箱验证码，验证码校验成功后才建立正式后台登录会话。
- 后台新增 SMTP / 邮箱验证配置区，支持配置 SMTP 主机、端口、发件邮箱、授权码、通知邮箱，以及开启/关闭后台邮箱二次验证。
- 后台账号设置页新增“安全邮箱绑定”模块，支持管理员为当前账号发送绑定验证码、完成邮箱绑定，并为后续邮箱二次验证提供绑定基础。
- 新增 SMTP 测试邮件能力，可在后台直接验证当前 SMTP 配置是否可正常发信。
- 新增 163 授权码到期监控基础能力，支持展示剩余有效天数、预计到期时间，并为后续提醒邮件提供自动检测能力。

## 【优化】
- 登录页交互升级：只有通过 Turnstile 后才允许点击“发送邮箱验证码”，并增加验证码发送冷却倒计时与验证码输入区切换逻辑。
- 后台登录态检查结果补充邮箱绑定状态、邮箱验证状态等字段，前端可更准确地识别当前账号是否需要先绑定安全邮箱。
- SMTP 配置保存逻辑增加“保留现有授权码”处理，管理员在只调整主机、通知邮箱等信息时无需重复填写授权码。
- 站点设置中的邮箱验证配置与登录页公共状态读取拆分为后台配置接口和登录页公共只读接口，避免未登录状态下暴露敏感 SMTP 信息。

## 【修复】
- 修复后台仅支持“用户名密码直登”的问题，现已支持在启用邮箱验证后通过邮箱验证码完成后台登录。
- 修复已开启邮箱验证时，未绑定邮箱账号缺少统一限制入口的问题；现在未绑定账号登录后会进入受限态，并被强制引导到邮箱绑定界面。
- 修复后台权限守卫只校验登录和权限、未校验“必须先绑定邮箱”状态的问题，防止未完成绑定的账号继续访问其他后台功能。
- 修复 SMTP 授权码更新后缺少到期重算与提醒历史清理的问题，避免旧的提醒状态影响新的授权码周期。

## 【说明】
- 当前邮箱二次验证默认面向全部后台账号生效；若账号已绑定并验证邮箱，登录时需完成“账号密码 + Turnstile + 邮箱验证码”三重校验。
- 当前未绑定安全邮箱的账号，在邮箱验证功能开启后仍可先进入后台受限态，但只能访问邮箱绑定相关功能，完成绑定后才可继续使用其他后台模块。
- SMTP 到期提醒默认按“最后设置授权码时间 + 180 天”推算，并在剩余 7 / 3 / 1 天时向“SMTP 通知邮箱”发送提醒邮件。
