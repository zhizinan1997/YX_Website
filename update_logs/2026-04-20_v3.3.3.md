# 版本: v3.3.3

更新时间: 2026-04-20 23:23:05

## 【新增】

- 后台资讯管理列表新增“排序”操作区，支持直接对新闻卡片执行上移、下移，并显示当前顺序编号，便于快速调整前台资讯展示顺序。
- 新增 `/api/news/reorder` 排序接口，后台可将资讯卡片顺序直接写回 `news.html`，使排序结果即时持久化生效。

## 【优化】

- 资讯列表重排逻辑升级，系统会按卡片展示顺序自动重建新闻卡片区块，并保留分页注释结构，方便后续维护与人工排查。
- 首页导航加载流程优化，新闻预览脚本改为在首页导航加载完成后按需注入，减少非首页的无效脚本加载。
- 新闻预览加载器增加重复初始化保护，避免脚本被重复注入时重复绑定逻辑，提升首页稳定性。

## 【修复】

- 修复首页与导航组件并存时，新闻预览脚本可能重复加载的问题，避免首页新闻预览模块重复执行。
- 修复资讯列表页“查看详情”按钮文案乱码的问题，恢复前台正常中文显示。
- 修复资讯详情页标题中的公司名称乱码问题，避免浏览器标签页与搜索结果展示异常。
- 修复资讯详情页“返回资讯列表”按钮文案乱码的问题，提升资讯阅读页可用性与一致性。

## 【说明】

- 本次 `v3.3.3` 主要聚焦于资讯模块体验优化，重点完成后台新闻排序能力补齐、首页新闻预览脚本加载治理，以及部分资讯页面中文乱码修复。
