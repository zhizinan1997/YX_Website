# 版本: v4.3.2

更新时间: 2026-07-06 11:05:00

## 【优化】
- AI 产品上架结构化生成改用独立 JSON-only 系统提示词，明确要求只返回标准 JSON 对象，顶层格式为 `{"sections": {...}}`，避免结构化生成流程被完整 HTML 页面提示词干扰。
- AI 产品结构化修订改用独立 JSON Patch 系统提示词，明确要求只返回 `{"patch": {...}}`，提升「暂存后重新编辑」和局部修改时的稳定性。
- 保留完整 HTML 生成与 HTML 修订接口的原有提示词和行为，结构化模式与源码模式各自使用匹配的 AI 输出格式。
- 产品详情页生成流程增加首屏布局保护，在桌面与常见平板宽度下保持「左侧产品图片、右侧产品信息与卖点」的展示结构。

## 【修复】
- 修复 AI 产品结构化生成时，模型可能按完整 HTML 页面要求输出源码，导致后台「AI 生成结果」为空或无法解析的问题。
- 修复 AI 返回 HTML 而非结构化 JSON 时错误信息不够明确的问题；现在会提示「AI返回了HTML而不是结构化JSON」，方便后台排查提示词或模型输出异常。
- 修复产品图缩略图替换时可能误匹配外层 `div`，导致产品首屏 DOM 结构错位、卖点区域掉到图片下方的问题。
- 修复部分 AI 生成产品页在常见桌面窗口下首屏被错误切换为上下布局的问题，1080p 等桌面环境默认保持左右布局。

## 【兼容与迁移】
- 本次更新不改变后台 API 路径、请求体或响应体，不影响现有产品页发布流程。
- 已发布的结构化产品页可通过重新保存或重新生成页面应用新的结构与响应式保护。
- 本次更新仅调整本地仓库代码与生成页面逻辑，部署到线上前需按常规流程更新服务并刷新浏览器缓存。

- 已补充产品页响应式保护测试，确保结构化生成页面会注入首屏布局保护与参数表移动端保护。
