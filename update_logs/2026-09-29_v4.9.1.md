# 版本: v4.9.1

更新时间: 2026-09-29

## 【版本概览】

- 本版本为发布流程更新：Windows 桌面客户端安装包随主站 Release 自动构建并挂载，无需再单独发桌面版标签。
- 不涉及后端与后台前端代码改动。

## 【桌面安装包随主站发布】

- 发布 `v4.x.x` 标签的 Release 时，桌面构建工作流会在 windows-latest 上同时构建 Tauri 桌面客户端的 NSIS 安装包，并挂到同一个 Release，桌面端版本号跟随站点标签（如 v4.9.1 → 4.9.1）。
- `desktop-v*` 标签保留为仅桌面外壳自身改动时的单独发版入口；镜像构建工作流仍只认 `v` 前缀，两种标签互不干扰，主站 `latest` 镜像不会被桌面版本号覆盖。
- 手动触发桌面构建工作流做发版前验证时，从分支启动不再因缺少版本号而失败，改为按仓库当前版本完成构建验证。
- 同步更新主 README 与 desktop/README 的发布流程说明。
