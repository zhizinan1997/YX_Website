# 版本: v2.18

更新时间: 2026-04-03 09:30:00

## 【修复】
- 修复产品案例页图片提取正则表达式转义错误，导致案例卡片图片始终无法显示的问题。
- 修复后台产品排序字段传入非数字值时接口直接返回 500 的问题。
- 修复留言 ID 仅使用时间戳生成、高并发提交时可能碰撞导致数据覆盖的问题。
- 修复留言表单各字段缺少长度限制，可被恶意提交超大内容耗尽磁盘的问题。
- 修复代理媒体失败时将 Python 异常堆栈细节泄露给客户端的问题。
- 修复后台 Markdown 回退渲染器未对内容做 HTML 转义，存在 XSS 注入风险的问题。
- 修复知识库文件删除接口未校验文件名合法性，理论上存在路径穿越风险的问题。
- 修复留言删除、标记已读、简历下载接口未校验 message_id 格式的问题。
- 修复 Turnstile 验证码安全设置缺少超级管理员权限检查，普通子管理员可修改的问题。
- 修复多处裸 `except` 语句可能吞掉 `SystemExit`/`KeyboardInterrupt` 的问题。

## 【运维】
- 一键部署脚本修复 `LEGACY_CDN_DIR` 变量未定义导致脚本无法运行的致命错误。
- 一键部署脚本补全重置模式下 `LEGACY_CDN_DIR` 的备份与清理逻辑，与用户确认提示保持一致。
- 一键部署脚本新增 `docker pull` 超时保护（默认 300 秒），防止网络异常时脚本无限挂起。
- 一键部署脚本新增容器启动后 HTTP 可用性验证（最长 15 秒轮询），替代原有仅检查进程的粗略判断。
- 一键部署脚本 `chmod` 权限修复失败时改为输出警告，不再静默忽略。
- 统一 `docker-compose.yml` 与部署脚本的默认端口（MAIN_PORT: 2026, CDN_PORT: 2027）。
