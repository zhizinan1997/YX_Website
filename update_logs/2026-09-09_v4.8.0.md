# 版本: v4.8.0

更新时间: 2026-09-09

## 【版本概览】

- 本次版本包含两大产品页新功能：**产品详情页「相关链接」自定义**与**产品画廊图片/视频混排**，并完成全量安全审计后的批量加固修复（路径穿越、XSS、SSRF、限流、竞态等）。
- 部署链路同步升级：Dockerfile 健康检查、升级脚本改进、可信代理 CIDR 支持。
- 全部改动已通过 209 项自动化测试。

## 【新功能：产品相关链接】

- 产品编辑后台新增「相关链接」板块，气敏/生物传感两个产品线均可为单个产品配置自定义链接列表（标题 + URL），随产品设置持久化保存。
- 产品详情页自动渲染相关链接区块，配套样式已加入 `yx-style.css`，后台管理界面（`legacy-admin.js` + `views.css`）同步支持增删改与排序。
- 新增相关链接数据校验与规范化逻辑，部分更新时继承既有配置，避免误清空。

## 【新功能：产品画廊视频】

- 产品画廊支持图片/视频混排：后台可直接为产品上传 MP4/WEBM 视频（单文件上限 100MB，扩展名与文件内容双重校验），存入 CDN `videos/` 目录。
- 前端画廊自动识别视频条目，视频自动静音播放，支持静音切换与全屏按钮；画廊主图区自动注入视频播放器容器（幂等升级，旧版产品页脚本自动替换为支持视频的新版本）。
- 上传接口 `/api/products/gallery-media/upload` 与生物传感线路 `/api/bio-products/gallery-media/upload` 均需登录，且校验文件签名，伪造扩展名直接拒绝。

## 【性能优化：首页首屏】

- 首页 Hero 轮播改为服务端引导注入：渲染 `index.html` 时把当前轮播配置以 `window.__HERO_BOOTSTRAP__` 内联写入首屏 HTML，浏览器首帧直接使用真实轮播图渲染，不再先画占位内容、再等 API 返回后重绘，消除首屏闪变与等待。
- API 返回后与引导配置比对，内容一致则跳过重绘，避免不必要的重排。

## 【修复：新闻乱码】

- 新增 `app/text_encoding.py` 显式修复历史上被错误解码的文本（如「查看详情」乱码序列），仅按已知乱码精确替换，不做宽泛重编码，避免误伤正常中文内容。
- 新闻与公开站点渲染链路统一接入修复函数，并补充编码与 SEO 测试。

## 【安全加固：全量审计修复】

- **路径穿越**：Hero/合作伙伴/新闻删除链路改为文件名白名单校验，封堵任意文件删除。
- **存储型 XSS**：后台留言中心 `escapeHtml` 补齐引号与消息 ID 转义；产品页 JS 内图片/链接 URL 全部转义输出。
- **CDN 安全**：rename 拒绝 `.html/.svg/.js` 等危险扩展名，`/cdn_assets` 全量响应加 `nosniff`。
- **验证码防爆破**：邮箱验证码三个端点接入 IP 限流与登录封禁，verify 复查账号状态；`/admin/check` 补齐会话时间戳与 schema 吊销校验。
- **会话治理**：子账号权限收窄、账号停用/密码重置后立即吊销既有会话；登出增加 CSRF 校验；登录尝试预检查封锁与延迟；邮件中的用户名转义。
- **SSRF 防护**：远程抓取逐跳重定向逐跳校验目标地址 + 流式限量读取；AI API base 拒绝内网/保留地址并禁用重定向；远程抓取主机后缀匹配收紧。
- **限流与竞态**：公开埋点改为流式限量读取（chunked 绕过 Content-Length 检查直接 413）；埋点 JSONL 超过 32MB 自动裁剪；埋点日志与后台登录日志加 `flock` 跨进程互斥，防读改写竞态。
- **上传校验**：图片上传以文件签名（magic bytes）优先，伪造 PNG（实际为 HTML）直接拒绝；各上传接口补齐大小上限。
- **备份安全**：备份解压改为流式分块 + 大小上限；备份排除清单/恢复黑名单补齐（Dockerfile、CI、日志、AI 报表）；备份下载/恢复接口加限流；智能合并拒绝运行时文件。
- **配置保护**：配置文件损坏时公开 GET 不再回写默认值覆盖管理员配置；审计日志改为原子写，损坏时不再回写空日志；地域规则部分更新继承当前配置，防止全大洲 DENIED 自锁。
- **代理信任**：新增 `TRUSTED_PROXY_CIDRS` 配置，仅显式声明的代理网段才信任 `X-Forwarded-For` 等头，防止公网客户端伪造 IP 绕过限流（默认保守策略）。
- **敏感信息**：`.dockerignore` 补齐运行时日志、passkey WAL、AI 报表等敏感文件；移除明文 HTTP 归属地解析器。
