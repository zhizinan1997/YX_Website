# 版本: v2.15.2

更新时间: 2026-03-30 14:51:51

- 新闻发布链路完成二次安全加固：资讯创建、更新、预览与历史页面统一收口到服务端净化逻辑，补上标题、摘要、日期、图片链接与正文 HTML 的安全清洗，降低存储型 XSS 风险。
- 历史资讯存量内容已批量净化：`pages/news/` 下历史新闻页面与 `news.html` 卡片索引已按新规则重写，避免旧内容残留危险标签、事件属性或 `javascript:` 链接。
- 产品发布高危能力已收权：原始整页 HTML 发布、产品源码覆盖上传、AI 配置改写等高风险入口改为仅超级管理员可执行，防止低权限子账号发布同源恶意页面或借接口外带密钥。
- 公开接口输出统一净化：首页推荐产品、解决方案、氢能首页产品/案例/新闻、产品相关推荐、导航预览等接口现在都会先清洗 `title`、`desc`、`summary`、`image`、`link`、`date` 后再返回，补上配置型 XSS 的最后一层服务端边界。
- 远程请求安全边界继续收紧：新闻图片导入、视频代理、CDN 连通性测试与相关远程媒体配置统一增加公网地址校验，拦截 `localhost`、内网/保留地址与重定向探测，进一步压缩 SSRF 面。
- 代理链 IP 解析逻辑已修正：`X-Forwarded-For` 改为按可信代理链自右向左解析真实客户端地址，降低伪造请求头绕过登录封禁、限流与审计记录的风险。
- 上传策略继续收口：合作伙伴 Logo 上传与 AI 产品图片上传不再接受 SVG，避免将同源主动内容文件写入公开可访问路径；新闻与产品卡图上传继续保持真实格式校验。
- 公开页安全响应头补齐并保持兼容：主站 HTML 响应继续注入基础 `CSP`、`X-Frame-Options`、`X-Content-Type-Options` 与 `Referrer-Policy`，在不改动现有页面路径和双层代理拓扑的前提下提升前端抗攻击能力。
- 本版本为安全修复与历史内容清洗版本，不新增业务功能、不调整现有页面访问路径；上线前请重新构建并部署应用容器，使新增的服务端净化与上传限制生效。
