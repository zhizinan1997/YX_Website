# 版本: v4.2.4

更新时间: 2026-06-18 18:00:00

## 【新增】
- 监测站公共仪表板和后台管理面板全面视觉升级：引入 Bootstrap Icons 图标库，指标卡、侧栏导航、按钮、异常记录等处均替换为语义图标；新增 CSS 动画（页面淡入、状态点脉冲呼吸、Hero 区域网格漂移）；卡片采用多层阴影和玻璃态效果，hover 时微抬反馈。
- 监测站后台异常告警页新增「清除全部记录」功能：需登录管理员身份，点击后弹出二次确认，确认后调用 `DELETE /api/admin/incidents` 接口删除所有异常记录，列表自动刷新。
- 一键升级脚本新增监测站容器支持：`dockerrun_upgrade.sh` 在执行主站镜像拉取和容器重建的同时，自动拉取 `yx_website-check` 镜像并同步更新监测站容器，复用旧容器的 `CHECK_SECRET_KEY`，首次部署时交互输入。

## 【优化】
- 监测站仪表板 Hero 区域加入动态网格纹理和径向光晕装饰，整体状态卡改为 `backdrop-filter: blur(16px)` 玻璃态；目标卡片左侧新增 4px 状态色条（绿/黄/红/灰），时间线柱子改为圆角并支持 hover 纵向放大。
- 监测站后台侧栏导航由中文字符标记（目/记/警）替换为 Bootstrap Icons（bullseye/clock-history/bell），折叠按钮改用 chevron 图标切换；KPI 卡片改为顶部渐变条装饰，按钮增加多层阴影和 hover 发光反馈。
- 一键升级脚本中监测站容器启动失败不影响主站运行，仅输出警告；回滚时自动恢复旧版监测站容器；验证阶段同时检测主站和监测站的 HTTP 可用性。
- 一键升级脚本新增 `CHECK_CONTAINER`、`CHECK_IMAGE`、`CHECK_PORT`、`CHECK_SECRET_KEY` 四个可覆盖环境变量，部署完成后输出监测站入口地址。

## 【修复】
- 修复一键升级脚本在 SSH 终端环境下输入被拒绝的问题：`IFS= read -r` 会捕获尾部回车符 `\r`，导致输入 `1` 实际为 `1\r` 无法匹配 `case` 分支。`trim()` 函数和 `prompt_line_into()` 均已加入显式 `\r` 去除逻辑。

## 【说明】
- 监测站视觉升级仅涉及前端样式和模板，不改变任何 API 接口和数据流，对已有部署无影响。
- 清除异常记录为物理删除，操作不可恢复；若监测目标后续再次检测失败，新的异常记录会自动重新生成。
- 监测站容器以只读方式挂载主站 `data/` 目录（读取 SMTP 配置和管理员邮箱），监测数据独立保存在 `check_data/` 目录。
- 从 v4.2.3 升级无需额外迁移步骤，升级脚本会自动检测并处理监测站容器。
