# 版本: v4.9.0

更新时间: 2026-09-26

## 【版本概览】

- 本版本集中优化后台常用页面的信息层次与操作密度，并为网站数据的 AI 报告增加生成前确认。
- 同时收录自 v4.8.3 以来已上线的线上店铺、试用申请、资讯、子账号与推广归因更新。

## 【后台导航与页面布局】

- 系统管理将账号设置、系统日志与站点设置组织为页内标签；AI 管理将客服配置、知识库和历史记录组织为并列标签，侧边栏保持默认展开，同时缩小顶部官网 Logo 并优化折叠按钮。
- 留言系统将访客留言与应聘信息分为标签页，增加搜索和状态筛选，降低页面初始展开内容的密度。
- 添加资讯、站点设置、系统日志等页面重新整理分区与操作入口；账号修改和安全邮箱绑定合并展示。
- 网站数据页面重新组织统计、趋势和明细，增加与上一周期的指标对比，压缩筛选及日志区域的占用空间。

## 【图片 SEO 资产编辑】

- 资产表改为紧凑列表与选中图片的编辑面板，集中编辑归属页面、角色、索引状态、Alt、标题和说明，减少窄屏横向滚动。
- 突出问题数量与重新扫描入口，将 Excel 导入导出收进次级菜单，统一帮助入口；常用筛选直接显示，其他筛选折叠展开，并按问题级别区分提示样式。
- 切换图片时暂存未保存编辑，在列表和编辑面板显示草稿状态；离开页面、忽略图片及导入 Excel 时提示可能产生的覆盖或未保存风险。

## 【AI 报告生成前确认】

- 点击“AI生成报告”后先查询所选报告周期及本期、上期日期范围，检查 API Key、模型、接口地址安全性和 HTTP 客户端是否可用，再显示确认弹窗。
- 配置不完整或不安全时停止生成并说明原因；预检接口仅返回必要的配置状态，不返回 API Key 或接口私有路径。

## 【官网与业务更新】

- 线上店铺页重做试用产品展示、分类筛选和自动轮播；申请试用表单支持从 URL 参数预填产品信息。
- 同步资讯 id_85 的列表、详情和配图，更新首页推荐位；修复飞书资讯导入报错导致后台误登出的问题。
- 新建子账号时支持设置并校验安全邮箱；归档推广链接后，其标记不再进入新留言归因，并与网站数据统计口径保持一致。

## 【测试】

- 补充 AI 报告预检的日期范围、权限、配置状态与敏感信息测试，并更新图片 SEO、网站数据页面的前端回归测试。
