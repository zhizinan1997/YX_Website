# 版本: v3.1.0

更新时间: 2026-04-06 16:45:32

## 【新增】
- 后台管理界面新增版本徽章（version-badge），实时显示当前网站版本号及构建时间
- 后台新增 `/api/changelog/latest` 接口，供前端获取最新版本信息
- 部署脚本新增容器创建后自动连接 bridge 网络的逻辑，确保端口映射和域名访问正常
- IP归属地解析服务新增 `fetch_ip_country_code` 专用函数，单独获取国家代码

## 【优化】
- IP归属地获取逻辑优化：`_fetch_ip_location` 系列函数现在返回 `(location, country_code)` 元组，country_code 直接使用 API 返回的正确 ISO 国家代码
- 国家登录地验证逻辑优化：`_is_ip_country_allowed` 函数改为直接使用国家代码进行验证，不再从地址文本中解析
- 登录接口增加返回 `current_login_ip` 字段，前端可正确区分本次登录IP与上次登录IP

## 【修复】
- 修复 `.gitignore` 配置，补充排除 `data/admin_users.json` 和 `data/site_analytics_events.jsonl`
- 修复后台导航栏设置页面权限目录渲染逻辑，使用动态权限键列表替代硬编码
- 修复登录信息显示时机问题：将 `updateTopbarAccountDisplay()` 调用移至权限目录初始化之后

## 【文档】
- README.md 升级脚本使用代理下载，增加 Docker 网络连接说明
- 移除 `docker-compose.yml`（改用脚本部署）
