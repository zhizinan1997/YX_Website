# 版本: v3.0.0

更新时间: 2026-04-04 22:15:42

## 【架构升级】
- 完成服务端主程序的大版本模块化重构，`server.py` 从集中式业务文件收敛为应用入口与启动编排层，业务逻辑、权限校验、请求安全、内容清洗、上传校验、后台审计等能力已拆分到 `app/` 与 `app/routes/` 独立模块。
- 新增统一接线模块 `app/bootstrap.py`，集中负责路由注册、共享依赖注入与模块装配，后续新增接口或继续拆分时可直接在接线层扩展，降低主入口文件复杂度。
- 保留新闻解析等兼容导出，确保现有本地工具脚本、管理接口和历史调用链在重构后仍能正常工作。

## 【模块化拆分】
- 完成站点统计模块拆分，独立承接埋点采集、事件清洗、统计聚合与后台报表接口。
- 完成媒体分发模块拆分，独立承接视频代理、CDN 设置、资源白名单与静态分发相关接口。
- 完成导航推荐与产品设置模块拆分，独立承接推荐位、导航预览、行业筛选、产品配置与卡片图片上传访问。
- 完成产品目录与内容聚合模块拆分，独立承接产品扫描、图片聚合、带设置产品列表与案例解析。
- 完成公共表单与消息中心模块拆分，独立承接反馈提交、Turnstile 公共校验、留言管理与招聘投递。
- 完成后台辅助能力拆分，独立承接管理员登录审计、IP 归属地解析、权限守卫、请求同源校验、远程拉取安全校验与可选依赖探测。

## 【工程整理】
- 统一补充并整理 `server.py`、`app/`、`app/routes/` 下模块说明、注册入口说明和关键函数注释，整体改为中文说明，便于后续维护、交接与继续拆分。
- 抽离运行时配置与应用初始化逻辑，统一由 `app/app_config.py` 管理应用创建、运行环境判断、配置读写与目录初始化。
- 抽离公开内容清洗与上传校验工具，减少跨模块重复实现，降低后续接口扩展时的耦合成本。

## 【修复】
- 修复拆分后 `create_app()` 所在位置变化导致 Flask `root_path` 偏移、进而使 `/admin` 等页面访问异常的问题。
- 修复直接执行 `python server.py` 时开发环境判断失效、被误判为生产环境并触发安全配置强校验的问题，恢复本地开发启动体验。
- 修复模块拆分过程中的接线兼容问题，确保后台管理、公开接口、产品详情、统计报表与消息中心等链路保持原有访问路径与返回结构。

## 【验证】
- 完成服务端模块全量语法校验，`server.py` 与 `app/*.py`、`app/routes/*.py` 编译通过。
- 完成后台登录、站点统计、媒体分发、产品配置、导航内容、消息中心等关键接口烟测，主要读写链路保持可用。
- 完成公开页埋点到后台报表的端到端联调，确认前端触发、事件入库、后台统计展示整条链路可正常工作。

## 【说明】
- `v3.0.0` 为服务端架构重构版本，重点在于完成模块化、提升可维护性与后续迭代效率；现有接口路径与核心使用方式保持兼容。
