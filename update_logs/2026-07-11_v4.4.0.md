# 版本: v4.4.0

更新时间: 2026-07-11

## 【新增】

- 新增后台功能权限解锁机制，可按管理员权限控制敏感功能入口与操作范围。
- 新增后台空闲超时和绝对会话超时机制，仅真实用户活动续期，降低长期占用会话的风险。
- 新增 AI 产品草稿工作流，支持创建草稿、结构化生成、多轮修改、保存、预览和正式发布。
- AI 产品编辑支持 JSON Patch 增量修改，减少多轮调整时整份内容被覆盖的概率。
- AI 产品上架支持产品图片上传、相关新闻、相关产品、富文本内容及高级 HTML 源码模式。
- 气体产品和生物产品的 AI 上架表单新增独立的“产品类型”与“领域分类”，不再固定写入 `detector` 或 `sensor`。
- 新增气体产品与生物产品排序功能，可在后台通过上移、下移调整前台展示顺序。
- 新增产品详情页咨询电话按钮配置，可按业务线控制电话文案是否显示，并在后台即时预览。
- 首页 Hero 区域支持按钮显隐配置，轮播内容支持点击后跳转至配置页面。
- 产品卡片新上传图片按业务线保存至 `cdn_assets/images/gassensing/` 或 `cdn_assets/images/biosensing/`。
- 产品 AI 配置支持通过环境变量提供，新增：
  - `PRODUCT_AI_API_KEY`
  - `PRODUCT_AI_API_BASE`
  - `PRODUCT_AI_MODEL`
- 聊天机器人配置支持通过环境变量提供，新增：
  - `CHATBOT_API_KEY`
  - `CHATBOT_API_BASE`
  - `CHATBOT_MODEL`

## 【优化】

- 重构 AI 产品生成协议，结构化生成结果必须包含顶层 `sections`，增量修改结果必须包含顶层 `patch`，减少格式漂移造成的解析失败。
- AI 草稿新增 `revision` 版本号，前端保存时提交 `expected_revision`；发现版本冲突时拒绝旧请求覆盖新内容。
- 前端自动保存改为串行执行，避免连续编辑产生的并发请求乱序写入。
- 产品发布采用跨进程锁、临时文件与原子替换，写入失败时自动回滚，降低并发发布或进程中断导致文件损坏的风险。
- 草稿 JSON 与产品设置 JSON 均增强并发写入保护；产品设置改为临时文件原子替换。
- 产品发布及产品设置保存后无条件清理产品缓存，确保新内容、排序、图片和按钮设置及时生效。
- AI 请求增加资源保护：每位用户每分钟最多 5 次请求，单进程最多同时处理 2 个 AI 请求；流式响应完成前持续占用并发名额。
- 产品详情页优化响应式布局，并增强参数表格保护，改善长内容和移动端展示。
- 气体与生物产品列表的产品图片区域统一为纯白背景，更适合白底产品图。
- 后台产品表格优先显示已配置的卡片图片，上传或修改后即时刷新预览。
- Turnstile 增加代理兜底与连通性检查，改善部分网络环境下的人机验证稳定性。
- 优化 PDF 内容分页、推广统计、SEO 元数据和页面资源引用。
- 更新后台相关静态资源版本标识，降低浏览器缓存旧 JS/CSS 导致功能未及时生效的概率。

## 【安全加固（完整汇总）】

- 后台权限与功能解锁统一在服务端校验，产品 AI 敏感配置仅允许超级管理员操作。
- 管理员登录增加安全邮箱绑定、验证码二次校验、IP/地域检查、Turnstile 和暴力破解封禁。
- 会话同时执行空闲超时、绝对超时和版本校验，仅真实用户活动可续期，旧会话自动失效。
- AI 密钥优先使用环境变量，`data/config.json` 退出版本控制；API Base 强制使用安全公网 HTTPS 地址，防范 SSRF 和内网探测。
- 产品 AI 增加每分钟请求限制和并发上限，流式请求结束前持续占用并发名额。
- AI 草稿按所有者和产品权限隔离，并通过 `revision` 乐观锁与串行自动保存防止越权和旧数据覆盖。
- 高级 HTML、结构化内容和 URL 统一安全校验，拒绝脚本标签、内联事件、脚本协议及其他持久化 XSS 内容。
- 上传同时校验请求体、真实文件大小、扩展名、Content-Type 和文件头 MIME，拒绝超大文件、SVG 及伪装图片。
- 上传路径执行规范化检查，阻止 `..`、路径分隔符和目录逃逸，新文件仅写入指定业务线目录。
- 草稿、产品设置和发布流程加入跨进程锁、临时文件、原子替换与失败回滚，避免并发写入损坏数据。

## 【修复】

- 修复 AI 多轮修改时旧的自动保存响应可能覆盖较新编辑内容的问题。
- 修复多个管理员或多个服务进程同时编辑、保存、发布时可能相互覆盖的问题。
- 修复 AI 结构化接口接受缺少 `sections` 或 `patch` 的异常结果，导致后续页面状态不完整的问题。
- 修复气体与生物产品 AI 上架时产品类型、领域分类被固定值覆盖的问题。
- 修复产品发布失败后可能留下半写入文件或部分更新状态的问题。
- 修复产品发布或设置保存后缓存未完全失效，前台短时间继续显示旧数据的问题。
- 修复产品卡片图片上传后后台预览仍显示旧图片的问题。
- 修复生物产品缺少独立排序入口，以及排序保存后前台可能仍按旧顺序展示的问题。
- 修复白底产品图在浅灰容器中边界突兀的问题。
- 修复产品参数表在窄屏或异常内容下可能溢出布局的问题。
- 修复部分 Turnstile 网络请求失败后缺少可用兜底的问题。
- 修复推广统计、转化归因、SEO 与 PDF 分页中的若干边界问题。

## 【兼容与迁移】

- 历史产品卡片路径 `/media/product-cards/` 继续兼容读取，新上传图片默认进入对应业务线的 CDN 素材目录。
- 产品排序继续使用现有产品设置文件中的 `sortOrder` 字段；未设置排序的产品按原有规则排列，无需手动迁移。
- 历史 AI 草稿如果没有 `owner`，会优先使用原有 `updated_by` 作为兼容归属；没有 `revision` 时按默认版本号兼容加载。
- 现有本地 `data/config.json` 可作为运行时兼容配置继续存在，但该文件已从 Git 跟踪中移除，后续不应随代码部署或提交。
- 环境变量优先于文件配置，未迁移环境变量前仍可读取兼容配置；生产环境应尽快完成迁移。
- 升级时必须保留线上 `data/` 目录中的管理员账号、留言、站点配置、统计数据、产品设置及其他用户数据，不要用仓库中的示例或本地数据覆盖线上数据。
- 若使用部署脚本，建议采用“重置界面，保留用户数据”或 `DEPLOY_STRATEGY=reset-keep-data`，用于刷新程序和静态资源并保留线上数据。
