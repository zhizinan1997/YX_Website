# 版本: v4.3.3

更新时间: 2026-07-08 16:41:49

## 【新增】
- 新增 Turnstile 服务端代理兜底能力：后台「登录人机验证（Cloudflare Turnstile）」可配置代理地址，例如 `http://glash:7890`，并可开启「直连失败后的代理重试兜底」。
- 新增 Turnstile 连通性测试：后台支持分别测试服务器直连 Cloudflare 与通过代理访问 Cloudflare 的可达性，便于排查阿里云出口到 Cloudflare 不稳定导致的登录验证码发送失败。
- 新增首页轮播主屏按钮显示开关：后台「首页设置 / 首页轮播」可控制官网首页首屏两个大按钮「生化传感事业部」「先进氢气传感解决方案」显示或隐藏。
- 首页轮播项新增点击跳转能力：每个轮播图或视频可单独启用跳转链接，支持在后台填写 `http(s)` 目标地址，前台点击轮播媒体后新窗口打开。
- 推广链接模块新增完整运营链路：支持创建、停用、隐藏、二维码生成、UTM 参数管理、访问数据查看和推广明细分析。
- 网站数据新增推广归因分析：可按推广标记、来源、媒介、活动和内容维度统计 PV、UV、会话、点击、转化、跳出率和平均停留等指标。
- AI 产品上架新增 HTML 源码模式、独立产品字段、相关新闻选择和相关产品选择能力，方便结构化生成与手工源码发布并行使用。
- 后台新增功能解锁配置与会话安全机制：支持按模块锁定后台功能，并引入空闲超时、绝对超时和真实用户活跃刷新。

## 【优化】
- Turnstile 校验默认仍优先直连 Cloudflare，仅在 timeout、connection reset、network unreachable、SSL handshake timeout 等网络类异常时才走代理重试，避免影响正常校验结果。
- Turnstile 代理兜底作用于全站共用校验链路，包括后台登录、公开表单、聊天机器人和监测站登录；SMTP、AI 接口和其它外部请求不走全局代理。
- Turnstile 后台设置接口扩展为统一保存启用状态、站点密钥、服务端密钥、代理地址和代理兜底开关；保存成功后登录页安全模式会即时刷新。
- 首页 Hero 配置新增 `cta_buttons_visible` 字段，旧配置缺失时默认显示两个主屏按钮，上传、删除和排序轮播项时会保留该开关。
- 首页轮播接口继续返回响应式图片源，同时新增按钮显示状态；前台在 `/api/hero` 返回后自动应用按钮显隐，不影响轮播加载与 fallback 首帧展示。
- AI 产品结构化生成与结构化修订分别改用 JSON-only 与 JSON Patch 专用提示词，降低模型误返回完整 HTML 的概率。
- 产品详情页生成流程加强首屏布局保护，桌面和平板宽度下优先保持左图右文结构，参数表在移动端以卡片式展示减少挤压。
- 后台推广链接、功能权限、AI 产品草稿、上传图片限制、预览 iframe 沙箱和公共页面 SEO 注入逻辑均完成增强，提升运营和发布稳定性。

## 【修复】
- 修复服务器直连 Cloudflare 不稳定时，后台登录可能在邮件验证码发送前失败的问题；现在可通过代理兜底恢复 Turnstile 服务端验签。
- 修复 Turnstile 网络失败与 Cloudflare 正常返回 `success:false` 难以区分的问题；正常校验失败不会触发代理重试，网络失败才会重试。
- 修复首页主屏两个大按钮只能通过改代码隐藏的问题；现在可由后台开关统一控制。
- 修复首页轮播点击跳转链接缺少后台校验的问题；非 `http://` 或 `https://` 链接不会被保存为有效跳转。
- 修复 AI 产品结构化生成时模型可能返回完整 HTML，导致后台结果为空或无法解析的问题。
- 修复产品图缩略图替换时可能误匹配外层结构，导致产品首屏 DOM 错位的问题。
- 修复后台会话仅按登录时间判断过期、功能锁定模块仍可能出现在权限目录或接口中的问题。
- 修复推广链接停用后仍可能被继续访问、留言详情缺少推广归因字段、部分公共页面 SEO 标签缺失或污染的问题。

## 【兼容与迁移】
- 新增主配置字段 `turnstile_proxy_url` 与 `turnstile_proxy_fallback_enabled`；缺失时默认不启用代理兜底，不影响现有 Turnstile 配置。
- Turnstile 代理仅支持 `http://` 和 `https://` 代理地址；生产环境建议将 `glash` 接入主站容器可解析的 Docker 网络别名后使用 `http://glash:7890`。
- 新增 Hero 配置字段 `cta_buttons_visible`；旧版 `data/hero/hero.json` 会按默认值 `true` 读取，无需手动迁移。
- 首页轮播项新增 `link_enabled` 与 `link_url` 字段；旧轮播项默认不启用跳转，原有图片、视频、排序和轮播间隔保持兼容。
- 推广链接新增 `data/promotion_links.json`，采用 JSON 文件存储；旧网站数据、管理员账号、留言、产品和新闻数据不需要迁移。
- 后台会话新增空闲超时和绝对超时配置，旧环境变量仍保留兼容；发布后建议刷新后台静态资源缓存，确保新设置项和按钮生效。
