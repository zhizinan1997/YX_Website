# 版本: v2.13

更新时间: 2026-03-27 18:45:00

- 修复部署一致性问题：定位并确认线上页面样式回退根因为 `docker run` 挂载 ` /app/pages ` 覆盖镜像内新页面，导致部分页面仍引用 `vaisala-style.css`。
- 更新 Docker Run 运维规范：`yx-website` 默认仅挂载 ` /app/data `，移除 ` /app/pages ` 与 ` /app/update_logs ` 的默认挂载示例，避免宿主机旧文件覆盖版本发布内容。
- README 部署指令重构：补充镜像 `pull` 步骤，统一“先拉取最新镜像再启动容器”的流程，降低“镜像已更新但运行内容未更新”的概率。
- 强化双容器端口说明：`yx-website` 不对宿主机映射端口，仅在 Docker 网络内提供 `8000`；`yx-gateway` 统一对外绑定 `127.0.0.1:2026:80` 与 `127.0.0.1:2027:81`，便于宝塔反代定位。
- 增加部署风险提示：文档明确“不要挂载代码目录（尤其 ` /app/pages `）”，如需持久化页面编辑能力需采用单独发布流程，不与运行镜像直接混挂。
- 本版本为运维与发布链路稳定性修复，不涉及接口协议变更与前台业务路径调整。
