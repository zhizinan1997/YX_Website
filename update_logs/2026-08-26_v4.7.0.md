# 版本: v4.7.0

更新时间: 2026-08-26

## 【版本概览】

- 本次版本围绕后台登录验证码、安全加固与多进程限流、后台导航栏可视化配置、新闻页脚统一注入、线上店铺样式重构与遗留资源清理进行集中升级。
- 后台登录新增阿里云 ESA 验证码支持，与既有 Cloudflare Turnstile 并存，可按环境选择验证码提供方。
- 系统性加固备份下载/恢复、CDN 上传、请求解析等安全边界，并将留言、简历等限流计数迁移到跨进程持久化存储，保证 Gunicorn 多 worker 部署下阈值一致。
- 后台首页设置新增导航栏设置，支持修改标题与链接、排序以及受保护的内置模块管理。
- 新闻详情页统一注入页脚组件；线上店铺页样式精简重构并同步 MC-MGM-02 产品 SEO 数据。
- 清理零引用的遗留脚本与图片资源，全项目文本差异为新增 6,373 行、删除 10,646 行。

## 【新增：阿里云 ESA 后台登录验证码】

- 新增后台登录验证码提供方配置，支持 `cloudflare`（Turnstile）与 `aliyun_esa`（ESA 验证码）两种方式，默认沿用 Turnstile。
- 新增 `ADMIN_CAPTCHA_PROVIDER`、`ADMIN_ESA_IDENTITY`、`ADMIN_ESA_SCENE_ID` 和 `ADMIN_ESA_REGION` 环境变量；未配置 ESA 参数时自动回落 Turnstile 或原有校验链路，不影响主站启动。
- 后台登录流程在密码验证前统一执行验证码前置校验，失败原因明确返回，便于前端区分验证码错误与凭据错误。

## 【安全加固】

- 新增 `app/rate_limit_store.py` 跨进程持久化限流存储：基于文件锁的计数器，在 Gunicorn 多 worker 部署下保证留言、分析上报等接口限流阈值全局一致；数据结构 v2 按桶记录各自时间窗口，旧版结构读取时自动迁移，避免不同业务窗口互相误清理。
- 备份下载安全收紧：备份包强制排除服务器密钥（`data/.flask_secret_key`）、站点凭据、管理员账号、登录日志、客户留言与求职简历等敏感文件和 PII 目录，防止凭据随备份离开服务器。
- 备份恢复安全收紧：恢复时禁止通过 ZIP 包向项目写入 `.py`、`.pyc`、`.sh`、`.bash`、`.env` 等可执行或配置文件，阻断持有备份权限的账号借“恢复”植入代码的路径。
- CDN 素材上传继续强化类型与内容校验，并补充对应安全测试用例。
- Flask 应用统一捕获 `BadRequest`：API 与 JSON 请求的解析错误保持 JSON 响应格式，不再泄露 HTML 调试页。
- 秘密密钥加载增加占位符识别，`change-me-in-production` 等常见占位值不再被当作有效生产密钥。
- 配置读写改用可重入锁（`RLock`），修复 `update_config()` 内部调用 `get_config()` 可能导致的死锁风险；运行目录创建收敛到 `ensure_runtime_directories()`，消除模块导入时的文件系统副作用。
- 登录尝试记录 JSON 回退逻辑修复，异常数据安全回退为 `{"ips": {}}`。

## 【新增：后台导航栏设置】

- 后台「首页设置」新增导航栏设置模块，支持修改导航项标题与链接、调整排序，权限并入首页设置（home）。
- 新增公开接口 `GET /api/nav-labels` 与管理接口 `POST /api/admin/nav-labels`，配置原子写入 `data/nav_labels.json`。
- 6 个核心模块（先进生化传感、先进气体传感、资讯精选、公司简介、线上店铺、联系我们）标记锁定，不可删除，仅允许改文案、链接和顺序。
- 前端 `nav-loader.js` 按稳定 key 覆盖静态导航文字与链接并重排，接口异常时自动回落默认导航，保证页面可用性。
- 资讯精选、公司简介、联系我们保留「含二级菜单」标识，避免误改 mega menu 入口。

## 【前台页面与体验】

- 新闻详情页统一由后端注入页脚组件，历史新闻静态页与新增页面（ID 至 80）页脚保持一致，并同步调整页脚与站内搜索样式。
- 新增站内搜索备用样式表 `assets/css/search_backup.css`，完善搜索浮层在不同主题下的兜底展示。
- 线上店铺页样式精简重构，删除冗余规则并统一卡片视觉，同步 MC-MGM-02 产品 SEO 数据与产品设置。
- 同步 MC-MGM 产品页线上状态；`.gitattributes` 扩展 LF 换行策略覆盖范围，减少跨平台换行符差异造成的无效 diff。

## 【依赖与部署说明】

- 升级 `gunicorn==23.0.0`、`werkzeug==3.0.6`、`requests==2.32.3`，包含上游安全修复。
- `server.py` 直接运行时默认进入本地开发模式（`APP_ENV=development`），debug 仅在开发环境开启，WSGI 导入时不再改变生产配置；`start.sh` 同步导出默认开发环境变量。
- 新增 ESA 验证码相关环境变量均为可选增强项；未配置时后台登录回退到 Turnstile 或原有校验链路。
- 限流数据现持久化于共享文件，多 worker 部署需确保各进程可访问同一 `data/` 卷。

## 【兼容与迁移】

- 导航栏未做任何自定义时，前端继续使用静态导航默认配置，行为与旧版完全一致。
- 旧版纯 list 结构的限流文件会在首次读取时自动迁移到 v2 结构，无需手工处理。
- 备份包内容较旧版更精简（不含密钥与管理员/PII 数据）；如需完整迁移管理员账号，应使用服务器侧直接复制 `data/` 的方式而非公开备份下载。
- 恢复功能不再接受源码与脚本类文件，历史备份中若包含此类条目将被跳过并记录。
