# 版本: v4.1.0

更新时间: 2026-06-03 13:34:01

## 【新增】
- 后台「添加资讯」正式上线飞书链接一键导入：粘贴已开启分享的飞书文档链接，即可自动填充标题、日期、正文与正文配图，作为新增资讯的默认推荐方式。
- 飞书导入支持正文图片自动转存到本站 `/cdn_assets/news/`，导入完成后提示「成功转存 N 张图片」，图片随正文一并落地，无需再手动逐张下载上传。

## 【优化】
- 飞书链接导入入口由原先的灰色禁用态升级为表单顶部的醒目推荐卡片，配「推荐」标识、图标与主色「一键导入」按钮，引导优先使用一键导入。
- 复制粘贴正文的方式调整为次要入口，仍可在下方手动填写或粘贴，满足无分享链接时的录入需求。
- 移除「添加资讯」菜单项与页面标题处的“测试版”角标，该能力由测试阶段转为正式功能。

## 【修复】
- 修复飞书正文图片无法自动转存、提示需登录权限（401 Login Required）的问题：导入时复用同一会话先加载分享页获取飞书匿名访问票据，再携带该会话与来源页地址下载图片，等同浏览器匿名访问的取图方式，实现图片稳定转存。

## 【说明】
- 飞书文档需开启「获得链接的人可阅读」的公开分享权限；若链接仍返回登录页，导入会提示将分享权限改为可直接访问后重试。
- 本次为前后端协同更新：后端完善飞书取图链路，前端解除灰度并将其设为推荐入口，资讯发布流程与既有正文清洗、封面/摘要生成逻辑保持兼容。
