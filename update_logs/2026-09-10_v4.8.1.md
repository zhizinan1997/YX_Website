# 版本: v4.8.1

更新时间: 2026-09-10

## 【版本概览】

- 本版本为**新闻资讯详情页全量视觉升级**：对全部 49 个新闻详情页统一重写页面样式与结构，显著提升阅读体验与品牌一致性；同时完成新闻配图本地化迁移。
- 不涉及后端逻辑与 API 变更，可直接热更新静态页面。

## 【新闻详情页美化】

- **Hero 头图区重做**：头图高度提升至 45vh 并预留固定导航空间（顶部内边距 90px），标题字号增大至 40px；每篇文章新增 `.article-hero__subtitle` 副标题层级；发布日期改为半透明圆角徽章样式并配日历图标，信息层级更清晰。
- **正文排版升级**：段落两端对齐，阅读更规整；二级小节标题（h2）增加品牌橙色左边框强调；正文图片放宽至 80% 宽度（最大 800px），新增阴影与圆角处理；无序/有序列表改为浅灰底卡片样式；新增 `.image-caption` 居中灰色图注样式。
- **响应式适配**：超宽屏（≥1920px）下正文容器收窄至 1200px 并同步放大标题与副标题，保证大屏阅读行宽舒适。

## 【新闻配图本地化】

- Hero 背景图由外部缓存目录（`/cdn_assets/images/external-cache/*.webp`）迁移至本地新闻图库（`/cdn_assets/news/`），消除对外部缓存路径的依赖，提升加载稳定性。
- 部分文章同步补全完整正文内容与配图图注。

## 【部署说明】

- 本版本仅涉及静态 HTML 与配图，生产环境可在运行中的容器内直接热更新 `/app/pages/news/` 目录，无需重建容器或重启服务。
