# 版本: v3.3

更新时间: 2026-04-11 18:50:09

## 【新增】
- 后台资讯编辑页补充飞书分享链接导入能力的后端基础支持，新增新版飞书 Docs 页面正文解析逻辑，可兼容 `CLIENT_VARS` 结构并提取标题、日期与正文 HTML。
- 飞书正文图片导入链路新增候选图片地址提取能力，开始复用飞书粘贴内容中的图片元数据解析思路，为后续继续完善飞书图片转存打基础。
- 后台图片转存状态提示升级为更醒目的横幅样式，支持处理中、成功、警告、失败等状态展示，并增加进度条与视觉强调。

## 【优化】
- 后台资讯编辑页的图片转换提示文案改为更直观的进度表达，例如“图片转存中 N/M”，减少编辑过程中的状态不确定感。
- 飞书导入与图片转存的失败日志补充了更明确的失败原因记录，便于区分链接校验失败、连接中断、未授权访问等不同问题。
- 飞书链接导入区域当前调整为灰色禁用态，在界面中直接显示“功能尚不完善，持续开发中”，避免误用未完成能力。

## 【修复】
- 修复 `/admin` 页面存在的中文乱码问题，恢复后台关键文案为正常中文显示。
- 修复新版飞书分享页无法识别正文、提示“未在分享页中解析到正文”的问题，现已可成功导入正文内容。
- 修复资讯编辑页图片转换提示不够醒目的问题，使批量图片转存过程更容易被注意到。

## 【说明】
- 当前飞书分享链接的正文导入已可用，但部分图片仍可能因飞书返回的下载地址需要登录权限而无法自动转存；在该能力完全稳定前，界面入口先保留灰态提示。
- 当前如需导入带图内容，建议优先通过浏览器打开飞书页面后复制正文并粘贴到后台编辑器，已有图片本地化逻辑可继续复用。
