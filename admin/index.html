新产品上架流程

模板位置（相对目录）
templates/gassensing-product-template.html
上架步骤
  1. 复制模板到 pages/gassensing/ 目录。
  2. 重命名文件（示例：mc_new_product.html）。建议仅用小写字母、数字、下划线。
  3. 按模板中的 TODO 修改内容：产品名称、主图、摘要、参数、正文。
  4. 必须修改 meta name=\"product-*\" 字段：name / short-name / image / description / category。
  5. 刷新后台 【氢气产品 → 产品列表】，确认新产品已被自动扫描。
  6. 在 【产品列表】 可选设置卡片标题/图片/摘要（留空则走默认值）。
  7. 在 【领域分类】 勾选该产品所属分类，最后前台强刷验证。
默认显示规则
当未在后台自定义卡片信息时，产品页会默认使用该产品 HTML 中的原始名称、原始图片和原始描述。
图片 产品名称 简称 分类 卡片标题（产品页） 卡片图片（产品页） 卡片摘要（产品页） 文件ID
提示：产品列表从 pages/gassensing/ 目录自动扫描。添加新产品只需创建对应的 HTML 文件即可。
不填写“卡片标题/卡片图片/卡片摘要”时，产品页将默认使用产品原始名称、原始图片和原始描述。
卡片图片支持两种方式：粘贴 HTTPS CDN 链接，或点击“本地上传”上传 PNG/JPG/JPEG/WEBP。
