推荐方式：Docker 部署 + 定期终端备份

建议生产环境使用 Docker / Docker Compose 部署，并定期在终端执行备份（建议每日或每周）， 这样即使重部署容器也能快速恢复数据。

1) 容器内执行备份（宿主机终端执行）

TS=$(date +%F_%H%M%S)
docker compose exec web sh -lc "cd /app && zip -r /tmp/yx_backup_${TS}.zip data pages pages_en assets/partials index.html index_en.html assets/js/nav-loader.js admin/index.html server.py"

2) 下载备份到宿主机（宿主机终端执行）

TS=$(date +%F_%H%M%S)
mkdir -p ./backups
FILE=$(docker compose exec web sh -lc "ls -t /tmp/yx_backup_*.zip | head -n1" | tr -d '\r')
docker compose cp web:${FILE} ./backups/

说明：如果你的服务名不是 web，请把命令中的 web 替换为实际服务名 （可用 docker compose ps 查看）。

完整备份下载

备份内容包含：data/（留言、应聘、招聘、上传文件、配置等）、 pages/、pages_en/（产品页/新闻页/招聘页/联系页等业务页面）、 index.html、index_en.html、assets/partials/、assets/js/nav-loader.js、 以及后台管理文件（admin/index.html、server.py）。

上传恢复（Docker 重部署后）

上传先前下载的 ZIP 备份包后将覆盖恢复对应目录。恢复成功后请重启服务并刷新后台页面。
